Hour 0–2 · Plan

  • Read the judging rubric
  • Write "done" in one sentence
  • Write the 90-second demo script
  • Pick the one demo path
  • Assign roles and owners
  • Agree on repo, branches, deploy target
  • Set up shared context (see below)

Scope · MoSCoW

  • Must The demo path only
  • Should Only after Must is deployed
  • Could "Future work" slide

Roles

  • FE Owns demo UI
  • BE Owns data and APIs
  • Glue Integration and deploy
  • Pitch Owns the story

Timeline

  • H4 Ugly skeleton live on a public URL
  • H12 Demo path works end to end
  • H20 Code freeze. Bug fixes only. Rehearse out loud with a timer.
  • H22 Record a backup demo video. Then sleep.

90-second demo script

1 PROBLEM One relatable sentence.

2 TRIGGER The moment the user acts.

3 AHA The thing that works live.

4 CLOSE Why it matters, what's next.

Shared context for agents

Start with one AGENTS.md under 200 lines. When files drift, share one live source:

# serve the team's docs folder
$ go install github.com/aakarim/\
  go-openlore/cmd/openlore@latest
$ openlore ./docs
# SSH :2222 · web + MCP :8080
$ ssh -p 2222 localhost \
  "grep -r 'auth' /"
$ claude mcp add --transport http \
  openlore http://localhost:8080/mcp
