Hour 0–2

Plan for two hours. It saves ten.

  • Read the judging rubric first
  • Write what "done" looks like in one sentence
  • Write the 90-second demo script, before any code
  • Pick the one path the demo will walk
  • Assign roles: frontend, backend, glue, presenter
  • Agree on repo, branches, deploy target and where shared context lives

Judging criteria decide more than raw technical merit. And balanced teams beat four backend engineers who can't explain what they built.

Scope

Cut scope like you mean it.

Must

The demo path only. Log in, do the one thing, see the result.

Should

Only if the Must is deployed and rehearsed.

Could

Goes on the "future work" slide. That's not failure, that's a roadmap.

Example: a study-buddy app. Must: upload notes, get a quiz. Could: accounts, sharing, streaks.

Workflow

Merge often. Freeze early.

# the whole git policy $ git switch -c feat/quiz-endpoint $ git commit -am "quiz endpoint" $ git pull --rebase origin main $ git push # PR, merge within 1h # T-2h: code freeze. # Only bug fixes on main.
  • Ugly skeleton live by hour 4
  • Small branches, merged within the hour
  • T-2h freeze. No last-minute heroics.
  • One person owns the deploy button

Meet OpenLore.

A knowledge base for AI agents. One place for docs, notes and runbooks that agents and people all read, live.

Learn something

Stop paying to re-read your codebase.

Agents already speak ls, cat and grep. No custom API to learn.

Without shared context

  • Every request, the agent scans the repo
  • Reads file after file to find the contract
  • Burns tokens before it writes a line

With OpenLore

  • Agent greps one shared source
  • Gets just the context it needs
  • Tokens go to shaping, so cost drops

One shared API contract would have connected our frontend and backend.

Trust

How do you stop a confident agent from overwriting the spec?

Read-only

The default. Writes are opt-in.

Scoped

Each identity sees only its own view.

Inbox

Agents publish findings for review, not straight to the spec.

Attributed

See who or which agent changed what, and when.

Plus per-document token budgets so agents don't drown in context. Runs as a pure-Go interpreter, with no shell escape.
